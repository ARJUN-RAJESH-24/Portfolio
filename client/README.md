# Portfolio Client

This directory contains the **React + Vite** frontend application for the portfolio.

For full project documentation, including design philosophy, tech stack, and deployment instructions, please refer to the **[Root README](../README.md)**.

## Quick Start (Client Only)

1. **Install dependencies:**

    ```bash
    npm install
    ```

2. **Run locally:**

    ```bash
    npm run dev
    ```

3. **Build for production:**

    ```bash
    npm run build
    ```
